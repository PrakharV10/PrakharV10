### Currently building

**[theme-bridge](https://github.com/PrakharV10/theme-bridge-core)** — one brand palette in, Ant Design + Tailwind v4 + CSS custom properties out. Audits WCAG contrast and refuses to emit an unreadable palette. Runs as `npx theme-bridge`.

**image-search** — natural-language search over a personal library of ~9,000 images. CLIP embeddings into Chroma, an incremental cache that only re-embeds what changed, and a UI over the query pipeline.

### Selected work

- **Healthcare reporting platform** — built the JSON-driven rendering engine behind client reports, taking report delivery from days to hours. Also led the white-label configuration layer, feature flags, and the monorepo the team still works in.
